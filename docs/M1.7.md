# M1.7 — Claude Code adapter

## What was built

`internal/adapter/claude/claude.go`: the live adapter of spec/02 §4.1.

- `Settings` / `MCPConfig` / `WriteConfig`: per-session `settings.json`
  (http hooks for every consumed event posting to `/hook/<token>`, plus
  `allowedHttpHookUrls`) and `mcp.json` (the single `court` http server),
  written under `<data-dir>/agents/<agent>/` — never the repository.
- `Start` launches `claude -p <prompt> --output-format stream-json
  --verbose --input-format stream-json --session-id <token> --settings
  <gen> --mcp-config <gen> --strict-mcp-config --permission-mode default`
  with the world as the process working directory (the tool has no
  working-directory flag). `Adapter.Bin` is the executable path so
  hermetic checks run a stand-in double (C1.7.3); the vendor SDK is not
  used.
- `Send` writes one SDKUserMessage JSON line to stdin; `Stop` closes
  stdin, waits up to 2 s for a clean exit, then kills.
- The outward-action deny policy (`policy.go`, wired in at M1.5) is
  evaluated by the daemon on every PreToolUse — the adapter only carries
  configuration.
