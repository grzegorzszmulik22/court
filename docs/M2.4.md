# M2.4 Writs and spawn

Public behavior added by this chunk. See
`spec/milestones/M2-commission-and-backbrief.md` §M2.4 and `spec/01` §9.

## Writs

A writ is the authority an agent works under: `agent`, `parent`,
`categories`, `class`, `territory` (globs), `budgets`. The human's root
writ to the orchestrator grants every non-guarantee category, class
`reversible`, the commission's territory and budgets.

Guarantee categories are outside every writ in version 1:
`test-strength`, `type-strength`, `guardrail`, `failure-handling`,
`authority`, `deletion`. Any requested writ naming one is refused.

## Attenuation

Every child writ must narrow its parent on all four dimensions:

- categories ⊆ parent's categories;
- every territory glob contained in the parent's territory, decided on
  the compiled glob automata (`internal/paths`), never on pattern text;
- class stays `reversible`;
- budgets fit inside the parent's *remaining* budget — each granted
  child deducts from the parent, so two spawns that together exceed the
  grant refuse the second.

## spawn

The `spawn` MCP tool takes `agent`, `task`, `categories`, `territory`,
`budgets`. On acceptance it emits `writ.issued`, forks a child world,
starts a child session with its own token, writ and task, and returns
the child's endpoints. On refusal it emits `writ.refused` (with the
rule and detail) and creates nothing — no world, no process.

## outside-writ

A declared decision whose category is not in the agent's writ, or whose
paths fall outside the writ's territory, is recorded with
`outside_writ: true` on `decision.declared`.
