# M1.6 — Agent tools

## What was built

- `internal/tools`: the session's MCP server on the official Go SDK
  (`github.com/modelcontextprotocol/go-sdk` v1.8.0, pinned). Exactly the
  three spec/02 §5 tools — `record_decision`, `claim_done`, `alarm` — no
  prompts, resources or sampling. `tools.ProtocolVersion` pins the
  protocol revision (`2026-07-28`).
- Validation: `record_decision` requires a question, a category from the
  closed spec/01 §4 list (a bad category is rejected with the whole
  list), a non-empty options list and a `chosen` that is one of the
  option ids; `claim_done` requires a task; `alarm` requires text.
  Validation failures come back as `isError` tool results the agent can
  read; the ledger's own body validation is the second line of defence.
- `internal/daemon/mcp.go`: `/mcp/<token>` serves one
  `StreamableHTTPHandler` (stateless + JSON responses, so the pinned
  revision works with no session header). The per-request server lookup
  binds the call to its session; each session gets one `*mcp.Server`
  whose emit closures carry the session's commission and resolved actor.
  The handler peeks at the request body to carry the JSON-RPC request id
  into the handler context (the SDK keeps it in an unexported key): the
  retry identity of a call is `mcp|<session>|<id>`, so a reposted request
  records once while two identical alarms or decisions are two events —
  never deduplicated on content.
- Subagent pairing: `actorForMCP` pops the oldest parked `PreToolUse`
  whose tool matches `mcp__*__<tool>` and returns its actor — so a child
  agent's `alarm` attributes to `<agent>:<agent_id>` even though the call
  arrived on the session's endpoint. The call goes agent→daemon directly:
  a parent that drops the message cannot intercept it.
- `internal/adapter/scripted.Client` speaks raw JSON-RPC over POST
  (initialize at the pinned revision, `tools/call`, `tools/list`), never
  sending a session header — that is the C1.6.4 client.

## Check results

C1.6.1–C1.6.5 PASS (validation incl. category list, 1,000 interleaved
calls across 8 agents with zero cross-attribution, child alarm through a
dropping parent, pinned-revision stateless transport, one-sentence
descriptions ≤200 chars). Sabotages: 3/3 caught, 0 uncaught.
