# M2.1 — Commission startup

## Public behavior

`court commission "<goal>"` is the one-keystroke entry point into Court.
It must be run inside a git repository; outside one it prints a single
sentence and exits non-zero.

What one invocation does, in order:

1. Resolves the repository root with `git rev-parse`.
2. Resolves the commission's data directory: `--data-dir <dir>` wins;
   otherwise a per-repository directory under the user state dir
   (`$COURT_STATE_DIR`, `$XDG_STATE_HOME/court`, or
   `~/.local/state/court`) keyed by the repository's absolute path.
3. Resolves done-checks: every `--done "<command>"` flag is used as
   given; with none, the repository layout is probed by detection rules —
   one per ecosystem — `go.mod` -> `go test ./...`, `package.json` ->
   `npm test`, `pyproject.toml` -> `python -m pytest`. The rule that
   fired is printed next to each detected command. When nothing is
   detectable the done-check list stays empty and one line says that
   done-claims cannot be checked.
4. Resolves territory: every `--territory <glob>` is used as given;
   with none, the whole repository `["**"]`.
5. Resolves budgets: `--tokens`, `--minutes`, `--attention <min/day>`
   or the built-in table (100000 tokens, 60 minutes, 2000 speculation,
   30 min/day attention).
6. Writes `commission.opened` to the ledger with the resolved values;
   `defaults` names every field the human did not supply (any of
   `done-checks`, `territory`, `tokens`, `minutes`, `speculation`,
   `attention`) — an explicit flag removes its name from the list.
7. Starts the daemon bound to the repository (or reuses a live one),
   mints a commission-unique orchestrator world
   `orchestrator-<commission-id>` and session, records `world.created`
   and `agent.started`, then launches the orchestrator: the scripted
   adapter with `--script <yaml>`, otherwise the Claude adapter.

Flags and the positional goal may be interleaved; `commission` takes
exactly one goal sentence. No configuration file, wizard, or
repository-read settings exist — one command starts work.

## Test hooks

- `--script <yaml>` runs the deterministic scripted orchestrator.
- `--data-dir <dir>` pins the data directory (checks use it).
- `COURT_STATE_DIR` overrides the per-repository data-dir root.
- The check binaries build with `go build ./cmd/court`; `COURT_BIN`
  points the test harness at the built binary.

## Check results

C2.1.1–C2.1.5 PASS. Sabotages: `default-territory-empty` caught by
C2.1.1 (the recorded territory is asserted `["**"]`),
`defaults-not-recorded` caught by C2.1.5 (the `defaults` list on
`commission.opened` is diffed against the defaults actually used).
