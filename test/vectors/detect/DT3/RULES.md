# DT3 interface — line rules

- `dt3-go-exported-removed` — exported Go identifier removed outside internal/.
- `dt3-go-exported-changed` — exported Go signature changed.
- `dt3-go-exported-added` — new exported identifier in a contract package.
- `dt3-python-toplevel-removed` — top-level public def/class removed.
- `dt3-python-toplevel-changed` — top-level public def signature changed.
- `dt3-python-toplevel-added` — top-level public def/class added.
- `dt3-ts-export-removed`, `dt3-ts-export-changed`, `dt3-ts-export-added` — exported TS symbol.
- `dt3-contract-openapi`, `dt3-contract-graphql` — contract file content change.
